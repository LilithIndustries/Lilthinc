01 / TWO REALITIES

Every organisation
contains two versions
of itself.

One is what the organisation believes is happening. The other is what its people, customers, systems and evidence show is actually happening.

We work in the distance between them. That is where dysfunction grows.

THE BELIEVED REALITY

The strategy is clear.

The dashboard is green.

Communication is open.

Each function is performing.

The transformation is on track.

THE GAP
THE EXPERIENCED REALITY

Meaning changes as strategy travels.

People have stopped escalating.

Important work does not move.

Handoffs quietly fail.

Workarounds keep the system alive.

We find the gap.

We uncover what is true.

We help close the distance.
